# My First Sample Repository

Welcome to my first Git repository! I created this project to learn the basics of version control, initializing a local repository, and pushing code to GitHub.

## 📁 Project Structure

This repository currently contains the following files:

* `README.md` — Documentation explaining the purpose of this repository.
* `index.html` — An empty placeholder file ready for future web development practice.

## 🚀 What I Learned

Through setting up this repository, I practiced the core Git workflow:

1. **Initialize** a local repository (`git init`)
2. **Stage** files for tracking (`git add .`)
3. **Commit** changes with a descriptive message (`git commit -m "Initial commit"`)
4. **Connect** the local repository to a remote GitHub repository (`git remote add origin <repo-url>`)
5. **Push** local commits to GitHub (`git push -u origin main`)
